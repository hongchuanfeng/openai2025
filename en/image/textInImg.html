How to Use

What is Add Text to Image?

This tool allows you to add customizable text overlays to any image. You can upload an image, add multiple text elements with different styles, positions, and effects, then download the final result.

How to Use

  1. Upload Image: Drag and drop an image or click "Select Image" to choose a file
  2. Add Text: Type your text in the text area and click "Add Text"
  3. Customize Style: Adjust font size, color, alignment, and text effects
  4. Position Text: Use the sliders to position text horizontally and vertically
  5. Select Text: Click on any text in the preview to edit it
  6. Add More Text: Repeat the process to add multiple text elements
  7. Save Image: Click "Save Image" to download the final result

Text Style Options

  • Font Size: Adjustable from 12px to 100px
  • Text Color: Choose any color using color picker or hex code
  • Alignment: Left, center, or right alignment
  • Text Effects: Bold, italic, underline, strikethrough
  • Text Shadow: Add shadow effect with adjustable intensity

Position Controls

  • Horizontal Position: 0% (left) to 100% (right)
  • Vertical Position: 0% (top) to 100% (bottom)
  • Real-time Preview: See changes instantly as you adjust

Supported Image Formats

  • JPEG (.jpg, .jpeg)
  • PNG (.png)
  • GIF (.gif)
  • WebP (.webp)
  • BMP (.bmp)

Common Use Cases

  • Adding captions to photos
  • Creating social media graphics
  • Adding watermarks to images
  • Creating memes and quotes
  • Adding labels to product photos
  • Creating announcement images
  • Adding text overlays to presentations

Tips for Best Results

  • Use contrasting colors for better text readability
  • Add text shadow for text on busy backgrounds
  • Position text in areas with less visual clutter
  • Use larger font sizes for better visibility
  • Test different alignments for the best visual balance
  • Consider the image composition when placing text

Text Selection and Editing

  • Click on any text in the preview to select it
  • Selected text will show a blue dashed border
  • Only the selected text will be affected by style changes
  • Use the Reset button to remove selected text
  • Add multiple texts for layered effects

Browser Requirements

This tool requires a modern browser with HTML5 Canvas support. Works on all major browsers including Chrome, Firefox, Safari, and Edge.

Important Notes

  • All processing is done client-side for privacy
  • No images or text are sent to external servers
  • Text positioning is relative to the image dimensions
  • You can add unlimited text elements
  • Each text element can be independently styled and positioned
  • Downloaded images maintain original quality
