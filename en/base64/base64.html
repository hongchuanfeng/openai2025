How Base64 works

  • Grouping: every 3 bytes (24 bits) are split into 4 groups of 6 bits.
  • Alphabet: each 6-bit value maps to one character from A–Z, a–z, 0–9, +, /.
  • Padding: if input length is not a multiple of 3, pad with 0 bits and append = or ==.
  • Text safety: Base64 is for transporting binary over text channels; it is not encryption.

How to Use

What this tool does

Encodes text to Base64 and decodes Base64 back to text using UTF‑8 safe conversion.

Steps

  1. Type text in Input → click Encode → see Base64 in Output.
  2. Paste Base64 in Output → click Decode → see text in Input.
  3. Swap switches the two boxes; Clear empties both.
