Escape编码

使用说明：

  • 1、在上方输入框输入内容，点击“Escape加密”得到已转义文本；或点击“Escape解密”将转义文本还原。
  • 2、可使用“交换内容”快速互换上下框内容；支持复制/下载结果。
  • 3、注意：原生 `escape/unescape` 已被废弃，建议在实际开发中使用 `encodeURIComponent/decodeURIComponent`。

示例：

  • 输入：`中 文` → Escape加密 → `%u4E2D%20%u6587`；将其解密可还原为 `中 文`。
