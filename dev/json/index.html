在线JSON格式化工具


    


    





	
使用说明：

	
    
		
  • 1、在输入框粘贴原始 JSON 字符串，点击“格式化”美化并在下方以树形展示。
    • 
		
  • 2、点击“复制”可复制格式化后的 JSON，点击“清空”重置页面。
    • 
		
  • 3、如提示错误，请确认 JSON 语法（引号、逗号、花括号/方括号配对）。
    • 
	

	
示例：

	
    
		
  • 输入：`{"name":"Tom","age":18,"tags":["js","web"]}` → 点击格式化后按缩进显示并树形预览。
